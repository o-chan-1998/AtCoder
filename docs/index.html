AtCoder Study Notes

ABC276 E - Round Trip

始点 S から出発して、壁を通らず、同じマスを重複せずに S へ戻れるかを判定する。 ポイントは「S の隣接マス同士が、S を使わずにつながっているか」を見ること。

要約 考察 実装 コード
Sample Article

問題の要約

グリッド上に始点 S、通れるマス .、壁 # がある。 S から上下左右に移動し、壁を避けながら、長さ4以上の閉路を作れるなら Yes、 作れないなら No を出力する。

問題ページ: AtCoder ABC276 E - Round Trip

考察

閉路は必ず S から隣の通れるマスへ出て、最後に別の隣接マスから S へ戻る。 つまり、S の隣にある通れるマスを入口候補として集め、そのうち2つ以上が S を通らずに同じ連結成分に属していればよい。

逆に、どの入口候補同士も S を使わずにつながっていないなら、 S に戻るための別ルートが存在しないため閉路は作れない。

S の周辺を見る

S #

S に隣接する通れるマスだけを入口候補にする。

S を通らずに探索

A ... B

探索中は S を壁と同じように扱う。

入口同士がつながるか

connected Yes

別の入口候補へ到達できれば、閉路を作れる。

解法方針

  1. S の位置を探す。
  2. S の上下左右にある . を入口候補として集める。
  3. 入口候補が2個未満なら、閉路は作れないので No。
  4. 各入口候補から BFS し、S を通らずに他の入口候補へ到達できるか調べる。
  5. 到達できる組があれば Yes、なければ No。

実装の注意点

探索中は grid[nr][nc] != "." のマスへ進まないようにする。 これにより # だけでなく S も通れない扱いになる。

学習用の sample.py はファイル入力だが、公開記事では AtCoder に提出しやすい標準入力版を載せる。

コード

from collections import deque

H, W = map(int, input().split())
C = [input().strip() for _ in range(H)]

sr = sc = -1
for r in range(H):
    for c in range(W):
        if C[r][c] == "S":
            sr, sc = r, c

directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
entrances = []

for dr, dc in directions:
    nr = sr + dr
    nc = sc + dc
    if 0 <= nr < H and 0 <= nc < W and C[nr][nc] == ".":
        entrances.append((nr, nc))

if len(entrances) < 2:
    print("No")
    raise SystemExit

entrance_set = set(entrances)

for start in entrances:
    visited = [[False] * W for _ in range(H)]
    queue = deque([start])
    visited[start[0]][start[1]] = True

    while queue:
        r, c = queue.popleft()

        if (r, c) in entrance_set and (r, c) != start:
            print("Yes")
            raise SystemExit

        for dr, dc in directions:
            nr = r + dr
            nc = c + dc
            if not (0 <= nr < H and 0 <= nc < W):
                continue
            if visited[nr][nc]:
                continue
            if C[nr][nc] != ".":
                continue

            visited[nr][nc] = True
            queue.append((nr, nc))

print("No")

まとめ

この問題は、閉路そのものを直接探すより、S の隣接マスの連結性に言い換えると見通しがよくなる。 S を通れないマスとして扱い、入口候補同士がつながるかだけを BFS で確認する。
