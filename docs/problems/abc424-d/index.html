問題の要約

黒いマスをいくつか白へ塗り替えて、黒だけでできた 2 x 2 が存在しない状態にする。 必要な塗り替え数の最小値を、複数テストケースについて求める。

問題ページ: AtCoder ABC424 D - 2x2 Erasing 2

考察

黒を白にするだけなので、最終的に残る黒は、最初の黒の部分集合である。 したがって「消す数を最小にする」は「残せる黒の数を最大にする」と同じである。

黒だけの 2 x 2 は、隣り合う2行の間にだけ発生する。 そこで、1行ごとに「どの列の黒を残すか」をビット列で表し、 直前の行状態と今の行状態が両立するかを見ながらDPする。

実装の注意点

幅は最大7なので、1行の状態は高々 2^7 通りである。 各行では、元から白いマスを黒として残す状態を除外する。 最後に 元の黒の総数 - 残せる黒の最大数 を答える。

コード

import sys


def compatible(upper, lower, width):
    for col in range(width - 1):
        mask = 3 << col
        if (upper & mask) == mask and (lower & mask) == mask:
            return False
    return True


def solve_case(h, w, grid):
    row_masks = []
    total_black = 0

    for row in grid:
        mask = 0
        for col, ch in enumerate(row):
            if ch == "#":
                mask |= 1 << col
        row_masks.append(mask)
        total_black += mask.bit_count()

    state_count = 1 << w
    minus_inf = -10**18
    dp = [minus_inf] * state_count

    for state in range(state_count):
        if state | row_masks[0] == row_masks[0]:
            dp[state] = state.bit_count()

    for row in range(1, h):
        next_dp = [minus_inf] * state_count
        for cur in range(state_count):
            if cur | row_masks[row] != row_masks[row]:
                continue
            add = cur.bit_count()
            for prev in range(state_count):
                if dp[prev] == minus_inf:
                    continue
                if compatible(prev, cur, w):
                    next_dp[cur] = max(next_dp[cur], dp[prev] + add)
        dp = next_dp

    return total_black - max(dp)


def solve():
    input = sys.stdin.readline
    t = int(input())
    answers = []

    for _ in range(t):
        h, w = map(int, input().split())
        grid = [input().strip() for _ in range(h)]
        answers.append(str(solve_case(h, w, grid)))

    print("\n".join(answers))


if __name__ == "__main__":
    solve()

つまずきポイント

DPで最大化しているのは、消す黒の数ではなく残す黒の数である。 問題で求める値へ戻すため、最後に元の黒の総数から引く。

まとめ

2 x 2 の制約は隣接2行だけで判定できる。 行状態をビットで持ち、両立する状態だけをつなげば、全体で残せる黒の最大数を求められる。
