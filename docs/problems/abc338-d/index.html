AtCoder Study Notes

ABC338 D - Island Tour

円環上の移動を、短い道を使う基準距離と、橋を封鎖したときに増える距離に分ける。 橋ごとの増加量は差分配列でまとめて更新する。

要約 考察 実装 コード
Article

問題の要約

N 個の島が円状につながっている。指定された島を順番に訪れるツアーについて、 橋を1本封鎖したときのツアー長の最小値を求める。

問題ページ: AtCoder ABC338 D - Island Tour

考察

円上の2点間には、橋番号が増える向きの道と、反対側を回る道の2通りがある。 まず各移動で短いほうを使った距離を合計し、これを基準距離にする。

ある橋を封鎖しても、短いほうの道にその橋が含まれていなければ、その移動の距離は変わらない。 含まれている場合だけ、反対側の道へ回る必要があり、 増加量は 長い距離 - 短い距離 になる。

基準

短い道Σ

各移動の短い距離を足す。

影響

封鎖橋∈短い道

含まれると反対側へ回る。

答え

基準+増加min

橋ごとの合計から最小を選ぶ。

解法方針

  1. 隣り合う訪問先 X_i と X_{i+1} の移動を1つずつ見る。
  2. 2通りの距離のうち短いほうを基準距離に足す。
  3. 短いほうに含まれる橋には、封鎖時の増加量を加える。
  4. 範囲加算は差分配列で行う。端をまたぐ範囲は2区間に分ける。
  5. 累積和で橋ごとの増加量を求め、基準距離 + 増加量 の最小値を出す。

実装の注意点

島 left から right へ番号が増える向きに進むと、 通る橋は left から right - 1。 反対側の道は端をまたぐので、1..left-1 と right..N に分けて更新する。

コード

def add_range(diff, left, right, value):
    if left > right:
        return
    diff[left] += value
    diff[right + 1] -= value


N, M = map(int, input().split())
X = list(map(int, input().split()))

base_distance = 0
diff = [0] * (N + 2)

for i in range(M - 1):
    a = X[i]
    b = X[i + 1]
    left = min(a, b)
    right = max(a, b)

    direct = right - left
    reverse = N - direct

    if direct <= reverse:
        short = direct
        long = reverse
        add_range(diff, left, right - 1, long - short)
    else:
        short = reverse
        long = direct
        add_range(diff, 1, left - 1, long - short)
        add_range(diff, right, N, long - short)

    base_distance += short

answer = 10**30
current_add = 0
for bridge in range(1, N + 1):
    current_add += diff[bridge]
    answer = min(answer, base_distance + current_add)

print(answer)

まとめ

すべての橋を封鎖してツアーを作り直すのではなく、短い道を基準にして増加量だけを見る。 「どの橋に同じ値を足すか」は区間になるため、差分配列で高速に処理できる。
