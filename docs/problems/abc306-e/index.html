ABC306 E - Best Performances

大きい方から K 個を上位グループとして保ち、その合計だけを更新する。

要約 考察 実装 コード
Article

問題の要約

最初すべて0の長さ N の数列がある。 各更新で1要素を指定された値に変更し、その時点の数列の大きい方から K 個の合計を出力する。

問題ページ: AtCoder ABC306 E - Best Performances

考察

更新のたびに数列全体をソートすると間に合わない。 必要なのは全体の順序ではなく、大きい方から K 個とその合計だけである。

そこで、現在の要素を2つのグループに分ける。 上位グループには大きい方から K 個を入れ、下位グループにはそれ以外を入れる。 答えは上位グループの合計なので、answer として常に持っておく。

更新では、古い値をどちらかのグループから消し、新しい値を入れる。 その後、上位グループの個数が K 個になることと、 上位グループの最小値が下位グループの最大値以上であることを保てばよい。

解法方針

  1. 上位 K 個を表すグループと、残りを表すグループを用意する。
  2. 上位グループの合計を answer として持つ。
  3. 更新では古い値を取り除き、新しい値をどちらかのグループに入れる。
  4. 上位が多ければ最小値を下位へ、少なければ下位の最大値を上位へ移す。
  5. 境界が逆転していたら、上位の最小値と下位の最大値を入れ替える。

実装の注意点

Python 標準ライブラリだけで多重集合を扱うため、2つのヒープを使う。 上位グループは最小ヒープにして、上位の中で一番小さい値をすぐ取り出せるようにする。 下位グループは値を負にした最大ヒープにして、下位の中で一番大きい値を取る。

ヒープから任意の要素を直接削除するのは難しいため、各添字に更新世代を持たせる。 古い値はヒープ内に残しておき、先頭に来たときに現在の値・所属グループと一致しなければ捨てる。

コード

import heapq
import sys


def solve():
    input = sys.stdin.readline
    n, k, q = map(int, input().split())

    values = [0] * (n + 1)
    versions = [0] * (n + 1)
    current_items = [None] * (n + 1)
    location = [None] * (n + 1)

    upper = []
    lower = []
    upper_size = 0
    lower_size = 0
    answer = 0

    for index in range(1, n + 1):
        item = (0, index, versions[index])
        current_items[index] = item
        if index <= k:
            heapq.heappush(upper, item)
            location[index] = "upper"
            upper_size += 1
        else:
            heapq.heappush(lower, (0, index, versions[index]))
            location[index] = "lower"
            lower_size += 1

    def is_current(item):
        value, index, version = item
        return current_items[index] == (value, index, version)

    def clean_upper():
        while upper:
            item = upper[0]
            _, index, _ = item
            if is_current(item) and location[index] == "upper":
                break
            heapq.heappop(upper)

    def clean_lower():
        while lower:
            negative_value, index, version = lower[0]
            item = (-negative_value, index, version)
            if is_current(item) and location[index] == "lower":
                break
            heapq.heappop(lower)

    def move_upper_to_lower():
        nonlocal upper_size, lower_size, answer
        clean_upper()
        value, index, version = heapq.heappop(upper)
        location[index] = "lower"
        upper_size -= 1
        lower_size += 1
        answer -= value
        heapq.heappush(lower, (-value, index, version))

    def move_lower_to_upper():
        nonlocal upper_size, lower_size, answer
        clean_lower()
        negative_value, index, version = heapq.heappop(lower)
        value = -negative_value
        location[index] = "upper"
        lower_size -= 1
        upper_size += 1
        answer += value
        heapq.heappush(upper, (value, index, version))

    def rebalance():
        nonlocal answer
        while upper_size < k and lower_size > 0:
            move_lower_to_upper()
        while upper_size > k:
            move_upper_to_lower()

        while upper_size > 0 and lower_size > 0:
            clean_upper()
            clean_lower()
            upper_value, upper_index, upper_version = upper[0]
            lower_negative, lower_index, lower_version = lower[0]
            lower_value = -lower_negative

            if upper_value >= lower_value:
                break

            heapq.heappop(upper)
            heapq.heappop(lower)

            location[upper_index] = "lower"
            location[lower_index] = "upper"
            answer += lower_value - upper_value

            heapq.heappush(lower, (-upper_value, upper_index, upper_version))
            heapq.heappush(upper, (lower_value, lower_index, lower_version))

    def remove_value(index):
        nonlocal upper_size, lower_size, answer
        old_value = values[index]
        if location[index] == "upper":
            upper_size -= 1
            answer -= old_value
        else:
            lower_size -= 1
        location[index] = None

    def add_value(index, value):
        nonlocal upper_size, lower_size, answer
        versions[index] += 1
        values[index] = value
        item = (value, index, versions[index])
        current_items[index] = item

        clean_upper()
        if upper_size < k or (upper and value > upper[0][0]):
            location[index] = "upper"
            upper_size += 1
            answer += value
            heapq.heappush(upper, item)
        else:
            location[index] = "lower"
            lower_size += 1
            heapq.heappush(lower, (-value, index, versions[index]))

    outputs = []
    for _ in range(q):
        x, y = map(int, input().split())
        remove_value(x)
        add_value(x, y)
        rebalance()
        outputs.append(str(answer))

    print("\n".join(outputs))


if __name__ == "__main__":
    solve()

つまずきポイント

上位グループは「値が大きいもの」だけでなく、同じ値が複数ある場合も区別して管理する必要がある。 そのため、ヒープには値だけでなく添字と更新世代も入れる。 また、answer は上位グループへ入るときに足し、出るときに引く。

まとめ

毎回ソートする代わりに、上位 K 個のグループを保つ。 上位グループの合計を更新しながら、個数と境界を調整すれば、各更新後の答えを効率よく出せる。
