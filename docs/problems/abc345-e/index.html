ABC345 E - Colorful Subsequence

削除数ごとに「最後の色と価値合計」の上位2件だけを残す。

要約 考察 実装 コード
Article

問題の要約

ボールをちょうど K 個取り除き、残った列で同じ色が隣り合わないようにする。 可能な場合、残る価値の総和の最大値を求める。

問題ページ: AtCoder ABC345 E - Colorful Subsequence

考察

K 個取り除く問題は、N-K 個を残す問題としても見られる。 残った列は元の順番を保つので、左から順に「取り除く」か「残す」かを決める。

残す場合に必要なのは、直前に残したボールの色である。 そのため状態には、取り除いた個数と最後に残した色、価値合計を持ちたい。

ただし、色をすべて持つと大きすぎる。 今の色 c のボールを残すときに必要なのは、 「最後の色が c ではない状態の最大値」だけである。 各削除数について上位2件を持てば、1位の色が使えない場合は2位を見るだけで済む。

解法方針

  1. dp[j] に、j 個削除した状態の上位2件を持つ。
  2. 各状態は (最後の色, 価値合計) とする。
  3. 今のボールを取り除く場合は、削除数を1増やし、最後の色と価値はそのまま。
  4. 今のボールを残す場合は、最後の色が今の色と違う状態から価値を足す。
  5. 各削除数について、常に上位2件だけを残す。

実装の注意点

初期状態は「まだ何も残していない」状態として、最後の色を番兵にする。 存在しない状態は十分小さい負の値にしておく。 答えは dp[K] の1位で、存在しなければ -1 である。

コード

import sys


NEG_INF = -10**30


def add_state(best, color, value):
    if value == NEG_INF:
        return

    first_color, first_value = best[0]
    second_color, second_value = best[1]

    if first_color == color:
        if value > first_value:
            best[0] = (color, value)
        return

    if second_color == color:
        if value > second_value:
            best[1] = (color, value)
            if best[1][1] > best[0][1]:
                best[0], best[1] = best[1], best[0]
        return

    if value > first_value:
        best[1] = best[0]
        best[0] = (color, value)
    elif value > second_value:
        best[1] = (color, value)


def solve():
    input = sys.stdin.readline
    n, k = map(int, input().split())
    balls = [tuple(map(int, input().split())) for _ in range(n)]

    dp = [[(-1, NEG_INF), (-1, NEG_INF)] for _ in range(k + 1)]
    dp[0][0] = (0, 0)

    for color, value in balls:
        next_dp = [[(-1, NEG_INF), (-1, NEG_INF)] for _ in range(k + 1)]

        for removed in range(k + 1):
            for last_color, total in dp[removed]:
                if total == NEG_INF:
                    continue

                if removed + 1 <= k:
                    add_state(next_dp[removed + 1], last_color, total)

                if last_color != color:
                    add_state(next_dp[removed], color, total + value)

        dp = next_dp

    answer = dp[k][0][1]
    print(answer if answer != NEG_INF else -1)


if __name__ == "__main__":
    solve()

つまずきポイント

各削除数で最大1件だけを持つと、その1件の最後の色が今の色と同じ場合に使えない。 そのため、別色の候補として2位まで保持する必要がある。

まとめ

左から順に残すか消すかをDPする。 最後の色をすべて持つ代わりに、削除数ごとの上位2件だけを残すことで、効率よく最大価値を求められる。
