ABC312 E - Tangency of Cuboids

小さい座標範囲を使い、空間を単位立方体で塗って面で隣り合う直方体を集める。

要約 考察 実装 コード
Article

問題の要約

3次元空間内に、互いに体積が正の重なりを持たない直方体がある。 各直方体について、他の直方体と面積が正の面で接している相手の数を求める。 点だけ、または線だけで接している場合は数えない。

問題ページ: AtCoder ABC312 E - Tangency of Cuboids

考察

直方体の個数は大きいため、全ペアを直接比較する方針は取りにくい。 一方で、各座標は 0 から 100 までに収まる。 空間全体を 1 x 1 x 1 の単位立方体に分けると、最大でも 100 * 100 * 100 個なので配列や辞書で扱える。

各直方体が占める単位立方体に、その直方体番号を書き込む。 その後、隣り合う単位立方体を調べ、所有者が異なる直方体番号なら、その2つは面で接している。 接触相手は集合に入れて、同じ相手を重複して数えないようにする。

点や線で接しているだけの場合は、単位立方体どうしが面で隣り合う組として現れない。 そのため、この方法では自然に「面積が正の接触」だけを拾える。

解法方針

  1. 各直方体について、範囲 x1 <= x < x2 などにある単位立方体を直方体番号で塗る。
  2. 塗られた各単位立方体から、正の x, y, z 方向の隣だけを見る。
  3. 隣も塗られていて、番号が違えば互いの接触相手集合に追加する。
  4. 最後に各直方体の集合サイズを出力する。

実装の注意点

直方体の右端の座標 x2, y2, z2 は、 単位立方体の開始座標としては含めない。 例えば x1 = 0, x2 = 2 なら、塗る x は 0 と 1 である。

隣接確認は正の3方向だけで十分。 負方向も見ると同じ組を逆向きに確認するだけなので、集合で消せるとはいえ処理が増える。

コード

import sys


def solve():
    input = sys.stdin.readline
    n = int(input())
    cuboids = [tuple(map(int, input().split())) for _ in range(n)]

    owner = {}

    for index, (x1, y1, z1, x2, y2, z2) in enumerate(cuboids):
        for x in range(x1, x2):
            for y in range(y1, y2):
                for z in range(z1, z2):
                    owner[(x, y, z)] = index

    contacts = [set() for _ in range(n)]
    directions = [(1, 0, 0), (0, 1, 0), (0, 0, 1)]

    for (x, y, z), current in owner.items():
        for dx, dy, dz in directions:
            neighbor = (x + dx, y + dy, z + dz)
            if neighbor not in owner:
                continue

            other = owner[neighbor]
            if current == other:
                continue

            contacts[current].add(other)
            contacts[other].add(current)

    print("\n".join(str(len(contact)) for contact in contacts))


if __name__ == "__main__":
    solve()

つまずきポイント

求めるのは接触している面の個数ではなく、接触相手の直方体数である。 広い面で接していると複数の単位立方体の隣接として見つかるため、集合で重複を消す。

まとめ

座標範囲が小さいことを使い、幾何判定を単位立方体の隣接判定に変換する。 空間を塗って隣を調べれば、面で接している相手だけを効率よく数えられる。
