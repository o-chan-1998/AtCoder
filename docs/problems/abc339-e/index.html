ABC339 E - Smooth Subsequence

最後の値ごとの最大長を持ち、値の範囲最大をセグメント木で求める。

要約 考察 実装 コード
Article

問題の要約

数列から部分列を選び、隣り合う要素の差の絶対値がすべて D 以下になるようにする。 そのような部分列の最大長を求める。

問題ページ: AtCoder ABC339 E - Smooth Subsequence

考察

部分列なので、元の順序を守る必要がある。 そのため、数列を左から順に処理する。

条件は隣り合う2項だけを見るものなので、今の値を末尾に追加するときは、直前の値だけが重要である。 dp[x] を「最後の値が x である部分列の最大長」とする。

今の値を a とすると、直前の値 x は a - D <= x <= a + D を満たす必要がある。 つまり、dp のこの範囲の最大値に1を足せば、a を最後にする最大長が分かる。

解法方針

  1. dp[x] を、最後の値が x の部分列の最大長とする。
  2. A を左から順に見る。
  3. 今の値 a について、[a-D, a+D] の範囲最大を求める。
  4. その値に1を足して、dp[a] を更新する。
  5. 範囲最大と一点更新を高速に行うため、セグメント木を使う。

実装の注意点

A_i の最大値は決まっているので、値そのものを添字にできる。 範囲 a-D や a+D は、配列の範囲からはみ出さないように丸める。

コード

import sys


class SegmentTree:
    def __init__(self, n):
        self.size = 1
        while self.size < n:
            self.size *= 2
        self.data = [0] * (self.size * 2)

    def query(self, left, right):
        left += self.size
        right += self.size
        result = 0

        while left < right:
            if left % 2 == 1:
                result = max(result, self.data[left])
                left += 1
            if right % 2 == 1:
                right -= 1
                result = max(result, self.data[right])
            left //= 2
            right //= 2

        return result

    def update(self, index, value):
        pos = index + self.size
        if self.data[pos] >= value:
            return
        self.data[pos] = value
        pos //= 2

        while pos:
            self.data[pos] = max(self.data[pos * 2], self.data[pos * 2 + 1])
            pos //= 2


def solve():
    input = sys.stdin.readline
    n, d = map(int, input().split())
    a_list = list(map(int, input().split()))

    max_value = 500000
    seg = SegmentTree(max_value + 1)

    for a in a_list:
        left = max(1, a - d)
        right = min(max_value, a + d)
        best = seg.query(left, right + 1)
        seg.update(a, best + 1)

    print(seg.query(1, max_value + 1))


if __name__ == "__main__":
    solve()

つまずきポイント

同じ最後の値なら、短い部分列を残す必要はない。 今後追加できる値は同じなので、最大長だけを残せば十分である。

まとめ

左から処理し、最後の値ごとの最大長を管理する。 絶対値条件は値の範囲最大に変換できるため、セグメント木で効率よく更新できる。
