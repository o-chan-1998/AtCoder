ABC346 E - Paint

操作を後ろから見て、最終的に色を決める行・列だけを数える。

要約 考察 実装 コード
Article

問題の要約

最初は全マスが色 0 の大きなグリッドに、行または列を塗り替える操作を行う。 すべての操作後、色ごとのマス数を求める。

問題ページ: AtCoder ABC346 E - Paint

考察

グリッド全体を持つことはできない。 さらに、必要なのは最終状態の盤面そのものではなく、色ごとの個数だけである。

あるマスの最終色は、そのマスに最後に影響した行操作または列操作で決まる。 そのため、操作を後ろから見ると、初めて出てきた行・列だけが新しく最終色を決める。

後ろから行操作を採用するとき、すでに最終色が決まっている列との交点は数えない。 その行で新しく決まるマス数は W - 決定済み列数 である。 列操作も同様に H - 決定済み行数 個を数える。

解法方針

  1. 操作をすべて保存する。
  2. 後ろから見て、すでに採用した行・列を集合で管理する。
  3. 未採用の行操作なら、まだ決まっていない列の数だけ色に足す。
  4. 未採用の列操作なら、まだ決まっていない行の数だけ色に足す。
  5. 最後まで決まらなかったマスは初期色 0 として足す。

実装の注意点

採用済みの行・列は集合で管理する。 同じ行や列が後ろから見て2回目以降に出てきた場合、それはより後の操作に上書きされているので無視する。 出力では、個数が正の色だけを色番号順に並べる。

コード

import sys
from collections import defaultdict


def solve():
    input = sys.stdin.readline
    h, w, m = map(int, input().split())
    operations = [tuple(map(int, input().split())) for _ in range(m)]

    fixed_rows = set()
    fixed_cols = set()
    color_count = defaultdict(int)

    for t, a, x in reversed(operations):
        if t == 1:
            if a in fixed_rows:
                continue
            color_count[x] += w - len(fixed_cols)
            fixed_rows.add(a)
        else:
            if a in fixed_cols:
                continue
            color_count[x] += h - len(fixed_rows)
            fixed_cols.add(a)

    color_count[0] += (h - len(fixed_rows)) * (w - len(fixed_cols))

    items = [(color, count) for color, count in color_count.items() if count > 0]
    items.sort()

    print(len(items))
    for color, count in items:
        print(color, count)


if __name__ == "__main__":
    solve()

つまずきポイント

前から塗ると上書きを追う必要がある。 後ろから見ると、各行・各列の最後の操作だけが意味を持つため、数える対象が明確になる。

まとめ

最終色を決める操作だけを後ろから採用し、担当する未決定マス数を色ごとに加算する。 大きなグリッドを作らずに、色ごとの個数だけを求められる。
