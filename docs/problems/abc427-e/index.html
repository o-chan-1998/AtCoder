ABC427 E - Wind Cleaning

現在残っているゴミ配置を状態にして、安全な上下左右の同時移動だけを BFS でたどる。

要約 考察 実装 コード
Article

問題の要約

グリッド上に高橋君と複数のゴミがある。 1回の操作では、すべてのゴミを上下左右の同じ方向へ1マス動かす。 ゴミが外へ出れば消え、高橋君のマスへ入る操作は使えない。 高橋君を汚さずにすべてのゴミを消す最小操作回数を求める。

問題ページ: AtCoder ABC427 E - Wind Cleaning

考察

操作回数を最小にしたいので、各操作のコストが1であることから BFS を使う。 状態として持つべきものは、現在グリッド上に残っているゴミの配置である。

ゴミはすべて同時に動く。外へ出たゴミは消え、以後戻らない。 そのため、単に「全体がどれだけ平行移動したか」ではなく、 どのゴミが残っているかまで含めた配置を状態にする必要がある。 

1つの状態から試す操作:
上 / 下 / 左 / 右

移動先が外      -> そのゴミは消える
移動先が T のマス -> その操作は使えない
それ以外        -> 次のゴミ配置に入れる

実装の注意点

H, W <= 12 なので、マス数は最大144である。 各マスに番号を振り、ゴミ配置を整数のビット列として表すと、訪問済み集合で扱いやすい。 新しい状態が 0 になったら、すべてのゴミを消せたことになる。

コード

import sys
from collections import deque


def cell_id(row, col, width):
    return row * width + col


def move_state(state, h, w, taka_row, taka_col, dr, dc):
    next_state = 0

    for pos in range(h * w):
        if ((state >> pos) & 1) == 0:
            continue

        row = pos // w
        col = pos % w
        nr = row + dr
        nc = col + dc

        if nr < 0 or nr >= h or nc < 0 or nc >= w:
            continue
        if nr == taka_row and nc == taka_col:
            return None

        next_state |= 1 << cell_id(nr, nc, w)

    return next_state


def solve():
    input = sys.stdin.readline
    h, w = map(int, input().split())
    grid = [input().strip() for _ in range(h)]

    start = 0
    taka_row = -1
    taka_col = -1

    for row in range(h):
        for col in range(w):
            if grid[row][col] == "#":
                start |= 1 << cell_id(row, col, w)
            elif grid[row][col] == "T":
                taka_row = row
                taka_col = col

    queue = deque([(start, 0)])
    visited = {start}
    directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

    while queue:
        state, dist = queue.popleft()

        for dr, dc in directions:
            next_state = move_state(state, h, w, taka_row, taka_col, dr, dc)
            if next_state is None:
                continue
            if next_state == 0:
                print(dist + 1)
                return
            if next_state in visited:
                continue

            visited.add(next_state)
            queue.append((next_state, dist + 1))

    print(-1)


if __name__ == "__main__":
    solve()

つまずきポイント

ゴミは1個ずつ順に動くのではなく、同時に移動する。 あるゴミが外へ出て消えた場合も、別のゴミが高橋君のマスへ入るなら、その操作全体は使えない。

まとめ

現在のゴミ配置を状態にして、4方向の安全な遷移だけを BFS で調べる。 初めて空配置に到達した距離が最小操作回数で、到達できなければ -1 である。
