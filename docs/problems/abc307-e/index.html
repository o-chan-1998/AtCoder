ABC307 E - Distinct Adjacent

円環に並ぶ人へ色を割り当て、隣同士が同じ色にならないようにする数え上げ。 1番目の色を固定し、今見ている位置が1番目と同じか違うかだけで状態を持つ。

Article

問題の要約

円環状に並んだ N 個の位置へ、M 種類の色を割り当てる。 隣接する位置の色がすべて異なるような割り当て数を、指定された法で求める。

問題ページ: AtCoder ABC307 E - Distinct Adjacent

考察

円環なので、最後の位置は1番目の位置とも隣接する。そこで1番目の色を一度固定して考える。 途中で必要なのは、今の位置の色が1番目と同じか、違うかだけ。

same

1番目と同じ

今見ている位置が、固定した1番目の色と同じ。

diff

1番目と違う

今見ている位置が、固定した1番目の色と違う。

最後

diffOK

円環を閉じるため、最後は1番目と違う必要がある。

解法方針

  1. 1番目の色を固定し、最後に M 倍する。
  2. same を「今の色が1番目と同じ」、diff を「違う」とする。
  3. 次の位置が same になるには、直前が diff である必要がある。
  4. 次の位置が diff になる選び方を、直前の状態ごとに数える。
  5. 最後の位置は1番目と違う必要があるので、答えは M * diff。

実装の注意点

same から diff へは、1番目以外の色を選ぶので M - 1 通り。 diff から diff へは、直前の色と1番目の色を避けるので M - 2 通り。

コード

MOD = 998244353

N, M = map(int, input().split())

same = 1
diff = 0

for _ in range(2, N + 1):
    next_same = diff
    next_diff = same * (M - 1) + diff * (M - 2)
    same = next_same % MOD
    diff = next_diff % MOD

print((M * diff) % MOD)

まとめ

円環をそのまま扱うと最後と最初の関係が邪魔になる。 1番目の色を固定し、現在地が1番目と同じか違うかだけを見ると、状態数を小さくできる。
