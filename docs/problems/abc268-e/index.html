ABC268 E - Chinese Restaurant (Three-Star Version)

各料理が本人の前に来る理想回転を数え、回転ごとの不満度合計を差分で更新する。

要約 考察 実装 コード
Article

問題の要約

円卓の周りに人と料理が番号付きで並んでいる。 テーブルを何回か回したあと、料理 i が人 i から円形距離でどれだけ離れているかを不満度とする。 全員分の不満度合計が最小になる回転回数を探す。

問題ページ: AtCoder ABC268 E - Chinese Restaurant (Three-Star Version)

考察

入力の p_i は「人 i の前にある料理」なので、まず料理ごとの現在位置 pos[dish] に直す。 料理 dish が本人の前に来る回転回数は、 (dish - pos[dish]) mod N である。

この値を理想回転と呼ぶことにする。 実際の回転回数 r におけるその料理の不満度は、 円環上で r と理想回転がどれだけ離れているかになる。

同じ理想回転を持つ料理は、回転に対する不満度の変化が同じである。 そこで cnt[c] を「理想回転が c の料理数」としてまとめる。 あとは f(0) を先に計算し、f(r) から f(r + 1) への増減だけを更新していく。

小さい例

入力例 N = 4, p = [1, 2, 0, 3] では、料理ごとの現在位置は次のようになる。 

pos[0] = 2
pos[1] = 0
pos[2] = 1
pos[3] = 3

理想回転はそれぞれ 2, 1, 1, 0 なので、 cnt = [1, 2, 1, 0] となる。 0回転での総不満度は 0*1 + 1*2 + 2*1 + 1*0 = 4。 1回転では料理1と料理2が本人の前に来るため、不満度合計は 2 まで下がる。

実装の注意点

f(0) は、各理想回転 c について min(c, N - c) * cnt[c] を足せばよい。 その後の更新では、回転を1進めたときに不満度が1減る料理数と、1増える料理数を数える。

円環上の範囲をまたいで数えるため、cnt を2周分に伸ばした累積和を作る。 区間内の料理数を prefix[right] - prefix[left] で取り出せるようにする。 N が偶数か奇数かで、真反対付近の扱いが1つずれる点に注意する。

コード

import sys


def circular_distance(n, a, b):
    clockwise = (a - b + n) % n
    counter_clockwise = (b - a + n) % n
    return min(clockwise, counter_clockwise)


def solve():
    input = sys.stdin.readline
    n = int(input())
    dishes = list(map(int, input().split()))

    pos = [0] * n
    for person, dish in enumerate(dishes):
        pos[dish] = person

    cnt = [0] * n
    for dish in range(n):
        ideal_rotation = (dish - pos[dish] + n) % n
        cnt[ideal_rotation] += 1

    current_total = 0
    for ideal_rotation in range(n):
        current_total += circular_distance(n, 0, ideal_rotation) * cnt[ideal_rotation]

    answer = current_total

    prefix = [0] * (2 * n + 1)
    for i in range(2 * n):
        prefix[i + 1] = prefix[i] + cnt[i % n]

    half = n // 2

    for rotation in range(n - 1):
        decrease_left = rotation + 1
        decrease_right = rotation + half + 1
        decrease_count = prefix[decrease_right] - prefix[decrease_left]

        if n % 2 == 0:
            increase_start = rotation + half + 1
        else:
            increase_start = rotation + half + 2

        increase_count = cnt[rotation]
        increase_count += prefix[rotation + n] - prefix[increase_start]

        current_total += increase_count - decrease_count
        answer = min(answer, current_total)

    print(answer)


if __name__ == "__main__":
    solve()

つまずきポイント

p_i は料理 i の位置ではなく、人 i の前にある料理である。 そのため、最初に pos[dish] = person へ変換する。 また、円環上の距離なので、端をまたぐ方が近い場合もある。

まとめ

料理を毎回動かして調べるのではなく、各料理が満足する理想回転を先に求める。 理想回転ごとの個数にまとめ、総不満度を差分更新すれば、全回転を効率よく確認できる。
