AtCoder Study Notes

ABC322 E - Product Development

複数のパラメータを目標値まで上げるため、どの開発案を採用するかを選ぶ。 各パラメータの現在値を状態にしたDPで、最小コストを管理する。

要約 考察 実装 コード
Article

問題の要約

N 個の開発案があり、それぞれコストと K 個のパラメータ上昇量を持つ。 すべてのパラメータを少なくとも P にするための最小コストを求める。

問題ページ: AtCoder ABC322 E - Product Development

考察

各パラメータの値をそのまま状態として持つ。ただし、目標は P 以上かどうかなので、 P を超えた値はすべて P に丸めてよい。

状態

(0, 1, 2)

各パラメータの現在値をタプルで表す。

遷移

選ぶ+cost

開発案を採用した場合の次状態へ、コストを加えて更新する。

丸め

P以上P

状態数を抑えるため、上限は P にする。

解法方針

  1. dp[state] = その状態へ到達する最小コスト とする。
  2. 初期状態はすべて0のタプル。
  3. 各開発案について、採用しない場合と採用する場合を考える。
  4. 採用する場合は、各パラメータを増やし、P を超えたら P に丸める。
  5. 目標状態 (P, P, ..., P) の最小コストを答える。なければ -1。

実装の注意点

1つの開発案を2回使わないように、各案を処理するときは現在の dp から next_dp を作って更新する。

コード

INF = 10**30

N, K, P = map(int, input().split())
plans = []

for _ in range(N):
    values = list(map(int, input().split()))
    cost = values[0]
    increases = values[1:]
    plans.append((cost, increases))

start = tuple(0 for _ in range(K))
goal = tuple(P for _ in range(K))
dp = {start: 0}

for cost, increases in plans:
    next_dp = dict(dp)

    for state, current_cost in dp.items():
        next_state = []
        for i in range(K):
            next_state.append(min(P, state[i] + increases[i]))
        next_state = tuple(next_state)

        next_cost = current_cost + cost
        if next_cost < next_dp.get(next_state, INF):
            next_dp[next_state] = next_cost

    dp = next_dp

answer = dp.get(goal, INF)
print(-1 if answer == INF else answer)

まとめ

複数の目標値を同時に扱うときは、値の組を状態として持てるかを考える。 今回は各値を 0 から P までに丸められるため、辞書DPで素直に更新できる。
