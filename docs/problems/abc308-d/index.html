AtCoder Study Notes

ABC308 D - Snuke Maze

左上から右下へ進めるかを調べる。上下左右の移動に加えて、 訪問文字が s n u k e の繰り返しになる条件を入れる。

要約 考察 実装 コード
Article

問題の要約

グリッドの左上から右下へ、上下左右に隣接するマスへ移動する。 訪れる文字が s → n → u → k → e → s の順番になる経路が存在するか判定する。

問題ページ: AtCoder ABC308 D - Snuke Maze

考察

求めるのは経路の存在なので、グリッド探索でよい。 ただし、今いるマスの文字から次に必要な文字が一意に決まるため、 隣接マスのうちその文字を持つマスだけを探索候補にする。

同じマスに一度到達できたなら、そこから先に必要な文字はそのマスの文字だけで決まる。 そのため、訪問済みはマス単位で管理すれば十分。

現在

s→n

s の次は n だけに進める。

移動

上下左右

斜め移動はできない。

判定

右下Yes

終点に到達できれば Yes。

解法方針

  1. 左上の文字が s でなければ No。
  2. 左上を始点として BFS または DFS を行う。
  3. 現在の文字から、次に必要な文字を求める。
  4. 上下左右の範囲内かつ未訪問で、次の文字に一致するマスだけへ進む。
  5. 右下へ到達できれば Yes、探索が尽きれば No。

実装の注意点

snuke の中で現在の文字が何番目かを調べ、次の添字を5で割った余りにする。 グリッドは最大で大きいので、再帰DFSではなくキューを使う BFS にすると扱いやすい。

コード

from collections import deque


H, W = map(int, input().split())
S = [input() for _ in range(H)]

word = "snuke"
if S[0][0] != "s":
    print("No")
    exit()

visited = [[False] * W for _ in range(H)]
queue = deque([(0, 0)])
visited[0][0] = True

directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

while queue:
    r, c = queue.popleft()
    if r == H - 1 and c == W - 1:
        print("Yes")
        exit()

    current_index = word.index(S[r][c])
    next_char = word[(current_index + 1) % len(word)]

    for dr, dc in directions:
        nr = r + dr
        nc = c + dc
        if not (0 <= nr < H and 0 <= nc < W):
            continue
        if visited[nr][nc]:
            continue
        if S[nr][nc] != next_char:
            continue

        visited[nr][nc] = True
        queue.append((nr, nc))

print("No")

まとめ

グリッド探索に、次の文字だけへ進む条件を足す問題。 状態はマスの位置だけで足りるため、通常の BFS/DFS とほぼ同じ形で書ける。
