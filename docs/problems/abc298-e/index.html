ABC298 E - Unfair Sugoroku

現在位置と手番を状態にして、各出目の先の勝率を平均するDPとして考える。

要約 考察 実装 コード
Article

問題の要約

高橋君と青木君が交互にサイコロを振り、先に地点 N に到着した方が勝つ。 高橋君が先手のとき、高橋君が勝つ確率を求める。

問題ページ: AtCoder ABC298 E - Unfair Sugoroku

考察

ある時点から先の勝率を決めるために必要なのは、高橋君の位置、青木君の位置、今どちらの手番かである。 過去の出目は、現在位置が同じなら今後の勝率に影響しない。

そこで、次の2種類のDPを用意する。 

T[i][j]: 高橋君が i、青木君が j にいて、高橋君の手番のときの勝率
A[i][j]: 高橋君が i、青木君が j にいて、青木君の手番のときの勝率

高橋君の手番では、各出目の先で高橋君がゴールすれば勝率は1。 ゴールしなければ次は青木君の手番なので A[next_i][j] を見る。 青木君の手番では、青木君がゴールした分岐の勝率は0で、そうでなければ T[i][next_j] を見る。

実装の注意点

位置は増えるだけなので、ゴールに近い状態から逆順に埋める。 確率の平均は、個数で割る代わりに pow(P, MOD - 2, MOD) と pow(Q, MOD - 2, MOD) を掛けて計算する。

コード

MOD = 998244353


def solve():
    n, start_t, start_a, p, q = map(int, input().split())

    inv_p = pow(p, MOD - 2, MOD)
    inv_q = pow(q, MOD - 2, MOD)

    turn_t = [[0] * (n + 1) for _ in range(n + 1)]
    turn_a = [[0] * (n + 1) for _ in range(n + 1)]

    for t in range(n - 1, 0, -1):
        for a in range(n - 1, 0, -1):
            total = 0
            for dice in range(1, p + 1):
                next_t = t + dice
                if next_t >= n:
                    total += 1
                else:
                    total += turn_a[next_t][a]
                total %= MOD
            turn_t[t][a] = total * inv_p % MOD

            total = 0
            for dice in range(1, q + 1):
                next_a = a + dice
                if next_a < n:
                    total += turn_t[t][next_a]
                total %= MOD
            turn_a[t][a] = total * inv_q % MOD

    print(turn_t[start_t][start_a])


if __name__ == "__main__":
    solve()

つまずきポイント

高橋君の手番と青木君の手番では、動く人も終了時の勝率も違う。 1つの表にまとめようとせず、手番ごとに2つの表を分けると遷移が読みやすい。

まとめ

現在位置と手番を状態にし、各サイコロの出目の先の勝率を平均する。 初期状態は高橋君の手番なので、答えは T[A][B] になる。
