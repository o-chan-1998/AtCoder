ABC357 E - Reachability in Functional Graph

サイクルを土台にして、外側の頂点の到達可能数を逆順に決める。

要約 考察 実装 コード
Article

問題の要約

各頂点から出る辺がちょうど1本の有向グラフで、 頂点 u から頂点 v へ到達できる組の個数を求める。

問題ページ: AtCoder ABC357 E - Reachability in Functional Graph

考察

求める答えは、各頂点から到達可能な頂点数の合計である。 出次数がすべて1なので、どの頂点から進んでも道は一本道になり、最終的には必ずサイクルへ入る。

サイクル上の頂点からは、そのサイクル上のすべての頂点へ到達できる。 長さ k のサイクルなら、サイクル上の各頂点の到達可能数は k である。

サイクル外の頂点 u は、出辺の先 a[u] へ進むしかない。 したがって、到達可能数は dp[u] = dp[a[u]] + 1 で決まる。

解法方針

  1. 各頂点の入次数を数える。
  2. 入次数0の頂点をキューで取り除く。取り除かれずに残った頂点がサイクル上の頂点である。
  3. 各サイクルをたどり、サイクル上の dp をサイクル長にする。
  4. 取り除いた頂点を逆順に処理し、dp[u] = dp[a[u]] + 1 で決める。
  5. 最後に dp の総和を答える。

実装の注意点

入次数0の除去で記録した順番は、外側からサイクルへ向かう順番である。 dp を求めるときは、出辺の先が先に決まっている必要があるので、この順番を逆に処理する。

コード

import sys
from collections import deque


def solve():
    input = sys.stdin.readline
    n = int(input())
    to = [0] + list(map(int, input().split()))

    indegree = [0] * (n + 1)
    for v in range(1, n + 1):
        indegree[to[v]] += 1

    queue = deque(v for v in range(1, n + 1) if indegree[v] == 0)
    removed = []

    while queue:
        v = queue.popleft()
        removed.append(v)
        nxt = to[v]
        indegree[nxt] -= 1
        if indegree[nxt] == 0:
            queue.append(nxt)

    dp = [0] * (n + 1)
    seen_cycle = [False] * (n + 1)

    for v in range(1, n + 1):
        if indegree[v] == 0 or seen_cycle[v]:
            continue

        cycle = []
        cur = v
        while not seen_cycle[cur]:
            seen_cycle[cur] = True
            cycle.append(cur)
            cur = to[cur]

        size = len(cycle)
        for x in cycle:
            dp[x] = size

    for v in reversed(removed):
        dp[v] = dp[to[v]] + 1

    print(sum(dp))


if __name__ == "__main__":
    solve()

つまずきポイント

サイクル外の頂点を前から何度もたどると重くなる。 サイクルを先に確定し、外側の頂点は逆順に1回ずつ処理すると線形時間で済む。

まとめ

Functional Graph は、サイクルとそこへ流れ込む枝として見る。 サイクル長を土台にし、外側へ +1 していくことで各頂点の到達可能数を求められる。
