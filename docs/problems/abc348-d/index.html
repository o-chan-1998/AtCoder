ABC348 D - Medicines on Grid

各マスに到達できる最大残りエネルギーを更新しながら、到達範囲を広げる。

要約 考察 実装 コード
Article

問題の要約

グリッド上で、エネルギーを消費しながらスタートからゴールへ移動できるかを判定する。 薬のあるマスでは、残りエネルギーをその薬の値にできる。

問題ページ: AtCoder ABC348 D - Medicines on Grid

考察

同じマスに到達する場合でも、残りエネルギーが多い状態のほうが強い。 そのため、各マスについて そのマスに到達できた最大残りエネルギー だけを持てばよい。

現在のエネルギーが 0 なら移動できない。 エネルギーが正なら、上下左右の通れるマスへ進み、移動後のエネルギーは1減る。 移動先に薬がある場合は、現在の残りと薬の値の大きいほうを採用する。

移動先で得られるエネルギーが、これまで記録した値より大きいときだけ更新する。 それ以外は、以前より弱い状態なので、そこから探索しても新しい到達先は増えない。

解法方針

  1. 薬の位置とエネルギーを辞書に入れる。
  2. スタート地点に薬がなければ、初期エネルギーが0なので No。
  3. best[r][c] を、そのマスに到達できた最大残りエネルギーとして持つ。
  4. キューで到達可能な状態を広げる。
  5. ゴールに到達できたら Yes、探索が尽きたら No。

実装の注意点

薬は必ず使う必要があるわけではない。 薬の値が現在の残りエネルギーより小さいなら、使わないほうがよい。 実装では max(移動後のエネルギー, 薬の値) として扱う。

コード

import sys
from collections import deque


def solve():
    input = sys.stdin.readline
    h, w = map(int, input().split())
    grid = [input().strip() for _ in range(h)]

    start = goal = None
    for r in range(h):
        for c in range(w):
            if grid[r][c] == "S":
                start = (r, c)
            elif grid[r][c] == "T":
                goal = (r, c)

    n = int(input())
    medicines = {}
    for _ in range(n):
        r, c, e = map(int, input().split())
        medicines[(r - 1, c - 1)] = e

    if start not in medicines:
        print("No")
        return

    best = [[-1] * w for _ in range(h)]
    sr, sc = start
    best[sr][sc] = medicines[start]
    queue = deque([(sr, sc, medicines[start])])
    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    while queue:
        r, c, energy = queue.popleft()

        if energy < best[r][c]:
            continue
        if (r, c) == goal:
            print("Yes")
            return
        if energy == 0:
            continue

        for dr, dc in directions:
            nr = r + dr
            nc = c + dc
            if nr < 0 or nr >= h or nc < 0 or nc >= w:
                continue
            if grid[nr][nc] == "#":
                continue

            next_energy = energy - 1
            if (nr, nc) in medicines:
                next_energy = max(next_energy, medicines[(nr, nc)])

            if next_energy > best[nr][nc]:
                best[nr][nc] = next_energy
                queue.append((nr, nc, next_energy))

    print("No")


if __name__ == "__main__":
    solve()

つまずきポイント

「薬のあるマスを頂点にしたグラフ」と見る解法もあるが、各マスの最大エネルギーを直接更新しても考えやすい。 同じマスへ弱い状態で来た場合は捨てる、という判断が重要である。

まとめ

到達できるかどうかだけでなく、どれだけエネルギーを残して到達できるかを管理する。 最大残りエネルギーを更新しながら探索すれば、ゴール可能性を判定できる。
