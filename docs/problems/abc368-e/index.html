ABC368 E - Train Delay

各駅で、時刻表上すでに到着した電車の最大実到着時刻を持つ。

要約 考察 実装 コード
Article

問題の要約

電車1の遅延が与えられる。 もともと乗り換え可能だった組が、遅延後も乗り換え可能であるように、各電車の遅延量を最小に決める。

問題ページ: AtCoder ABC368 E - Train Delay

考察

条件は、乗り換え元の実到着時刻が、乗り換え先の実発車時刻以下であることを要求している。 電車 j の遅延量を決めるには、発車駅 A_j に時刻表上すでに到着している電車の 実到着時刻の最大値を見ればよい。

latest[v] を、街 v に時刻表上すでに到着した電車の最大実到着時刻とする。 電車 j の発車時には、 X_j = max(0, latest[A_j] - S_j) とすれば必要最小の遅延になる。

電車が到着したら、その実到着時刻 T_j + X_j で latest[B_j] を更新する。 これを正しい順番で処理するため、発車イベントと到着イベントを時刻順に並べる。

解法方針

  1. 各電車について、発車イベントと到着イベントを作る。
  2. イベントを時刻順にソートする。同時刻なら到着を先に処理する。
  3. 到着イベントでは、到着駅の latest を実到着時刻で更新する。
  4. 発車イベントでは、電車1以外の遅延量を max(0, latest[発車駅] - 発車時刻) で決める。
  5. X_2..X_M を出力する。

実装の注意点

同じ時刻に到着と発車がある場合、時刻表上は乗り換え可能なので到着を先に処理する。 そのため、イベント種別は到着を小さい値にしてソートする。

コード

import sys


def solve():
    input = sys.stdin.readline
    n, m, x1 = map(int, input().split())

    a = [0] * (m + 1)
    b = [0] * (m + 1)
    s = [0] * (m + 1)
    t = [0] * (m + 1)

    events = []
    for train in range(1, m + 1):
        a[train], b[train], s[train], t[train] = map(int, input().split())
        events.append((t[train], 0, train))
        events.append((s[train], 1, train))

    events.sort()

    delay = [0] * (m + 1)
    delay[1] = x1
    latest = [0] * (n + 1)

    for _, event_type, train in events:
        if event_type == 0:
            city = b[train]
            latest[city] = max(latest[city], t[train] + delay[train])
        else:
            if train == 1:
                continue
            city = a[train]
            delay[train] = max(0, latest[city] - s[train])

    print(" ".join(map(str, delay[2:])))


if __name__ == "__main__":
    solve()

つまずきポイント

乗り換え元を電車ごとにすべて探す必要はない。 発車駅ごとに最大の実到着時刻だけを持てば、その駅で待つべき最小遅延が決まる。

まとめ

発車と到着を時刻順イベントとして処理する。 各駅の最大実到着時刻を更新し、各電車は発車時にその値まで待つことで、最小の遅延量を求められる。
