ABC282 D - Make Bipartite 2

追加候補を1本ずつ試さず、二部グラフの色分けから追加できないペアをまとめて引く。

要約 考察 実装 コード
Article

問題の要約

無向グラフにまだ存在しない辺を1本追加するとき、追加後のグラフが二部グラフになるような 頂点ペアの個数を求める。

問題ページ: AtCoder ABC282 D - Make Bipartite 2

考察

追加後のグラフが二部グラフなら、追加前のグラフも二部グラフでなければならない。 そのため、まずグラフ全体を連結成分ごとに2色で塗り、隣り合う頂点が同じ色になる矛盾があれば答えは 0 になる。

元のグラフが二部グラフだった場合、追加候補は「全ての頂点ペア」から「すでに存在する辺」を除いた非辺である。 非辺の数は N * (N - 1) / 2 - M 個ある。

この非辺のうち、追加してはいけないのは 同じ連結成分内で、同じ色に塗られた頂点どうし である。 同じ色どうしを結ぶと、二部グラフの条件を壊してしまう。

一方、違う連結成分どうしなら、片方の成分の黒と白をまるごと反転できる。 そのため、違う連結成分に属する2頂点の間には、どの組み合わせでも辺を追加できる。

解法方針

  1. 隣接リストを作る。
  2. BFS または DFS で各連結成分を2色に塗る。
  3. 塗っている途中で、隣接頂点が同じ色なら 0 を出力する。
  4. 答えの初期値を N * (N - 1) / 2 - M にする。
  5. 各連結成分について、色0の個数を a、色1の個数を b とする。
  6. 同じ成分内の同色ペア aC2 + bC2 を答えから引く。

小さい例

たとえば、ある連結成分が {1, 2, 3} で、 色分けが {1, 3} と {2} に分かれたとする。 この成分内では、違う色の間には辺を追加できるが、同じ色の (1, 3) は追加できない。

色0が2個、色1が1個なので、追加できない同色ペアは 2C2 + 1C2 = 1 個である。 これを各連結成分について足し合わせ、非辺の総数から引けばよい。

実装の注意点

頂点数と辺数が大きいので、追加候補の頂点ペアを列挙して試すことはできない。 必要なのは各連結成分の色ごとの個数だけなので、探索中に [0色の個数, 1色の個数] を数えればよい。

孤立頂点も1つの連結成分として扱う。 たとえば色0を1個、色1を0個として数えれば、同色ペアは 0 個になる。

コード

import sys
from collections import deque


def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())

    graph = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        graph[u].append(v)
        graph[v].append(u)

    color = [-1] * n
    answer = n * (n - 1) // 2 - m

    for start in range(n):
        if color[start] != -1:
            continue

        color[start] = 0
        queue = deque([start])
        count = [1, 0]

        while queue:
            current = queue.popleft()

            for next_vertex in graph[current]:
                if color[next_vertex] == -1:
                    color[next_vertex] = 1 - color[current]
                    count[color[next_vertex]] += 1
                    queue.append(next_vertex)
                elif color[next_vertex] == color[current]:
                    print(0)
                    return

        black, white = count
        answer -= black * (black - 1) // 2
        answer -= white * (white - 1) // 2

    print(answer)


if __name__ == "__main__":
    solve()

つまずきポイント

同じ色どうしがだめなのは、同じ連結成分内だけである。 違う連結成分どうしは色の呼び方を反転できるため、同じ色に見えていても追加できる。

まとめ

まず元のグラフが二部グラフかを確認する。 二部グラフなら、全ての非辺から各連結成分内の同色ペアを引くことで、条件を満たす追加辺の個数を求められる。
