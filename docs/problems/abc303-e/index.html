ABC303 E - A Gift From the Stars

完成した木を逆から見て、葉の隣にある星の中心を取り出していく。

要約 考察 実装 コード
Article

問題の要約

いくつかの星型グラフを、外側の頂点どうしに辺を張って1本の木にした。 完成後の木から、最初にあった星のレベルをすべて復元する。

問題ページ: AtCoder ABC303 E - A Gift From the Stars

考察

星どうしをつなぐ操作では、次数1の外側の頂点だけが選ばれる。 星の中心は選ばれないので、中心の次数は最初の星のレベルのまま残る。

木の葉を見ると、その葉はどれかの星の外側の頂点である。 したがって、葉の隣はその星の中心であり、その次数が復元すべきレベルになる。 中心とその隣接頂点を取り除くと、隣の星の外側が新しい葉になる。

解法方針

  1. 各頂点の最初の次数を保存する。
  2. 現在の次数が1の頂点をキューに入れる。
  3. 葉を取り出し、まだ残っている隣接頂点を中心とする。
  4. 中心の最初の次数を答えに追加する。
  5. 中心とその隣接頂点を削除し、新しく葉になった頂点をキューに入れる。
  6. 最後にレベルを昇順に並べて出力する。

実装の注意点

削除済みの頂点をキューから取り出すことがあるので、その場合は無視する。 レベルとして使うのは、削除後の次数ではなく、入力された木での最初の次数である。

コード

import sys
from collections import deque


def solve():
    input = sys.stdin.readline
    n = int(input())
    graph = [[] for _ in range(n)]

    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        graph[u].append(v)
        graph[v].append(u)

    original_degree = [len(graph[v]) for v in range(n)]
    current_degree = original_degree[:]
    removed = [False] * n

    queue = deque(v for v in range(n) if current_degree[v] == 1)
    levels = []

    while queue:
        leaf = queue.popleft()
        if removed[leaf]:
            continue

        center = -1
        for to in graph[leaf]:
            if not removed[to]:
                center = to
                break

        if center == -1:
            continue

        levels.append(original_degree[center])
        erase = [center] + graph[center]

        for v in erase:
            if removed[v]:
                continue
            removed[v] = True
            for to in graph[v]:
                if removed[to]:
                    continue
                current_degree[to] -= 1
                if current_degree[to] == 1:
                    queue.append(to)

    levels.sort()
    print(*levels)


if __name__ == "__main__":
    solve()

つまずきポイント

「葉の次数」ではなく「葉の隣の次数」を見る。 葉は星の外側であり、レベルを持っているのは中心である。

まとめ

生成操作を逆向きに見ると、端の星を葉から見つけて取り外す処理になる。 中心の最初の次数を集めることで、元の星のレベルを復元できる。
