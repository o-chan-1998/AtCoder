AtCoder Study Notes

ABC296 D - M<=ab

片方の値を固定し、もう片方を切り上げ除算で決める。

要約 考察 実装 コード
Article

問題の要約

1 以上 N 以下の整数 a, b の積として表せる数のうち、 M 以上で最小のものを求める。

問題ページ: AtCoder ABC296 D - M<=ab

考察

a と b を両方すべて試すことはできない。 そこで a を固定して考える。 条件 a * b >= M を満たす最小の b は ceil(M / a) で決まる。

あとは、その b が N 以下なら a * b を答え候補にする。 b を順番に探す必要はない。

また、積は a * b = b * a なので、 小さい方を a として見れば十分である。 そのため、調べる a は sqrt(M) 付近まででよい。

解法方針

  1. N * N < M なら、最大の積でも届かないので -1。
  2. a を 1 から min(N, sqrt(M) + 1) まで試す。
  3. 各 a について、必要な最小の b を (M + a - 1) // a で求める。
  4. b <= N なら、a * b で答えを更新する。

実装の注意点

N と M は大きいので、浮動小数点の平方根に頼らず math.isqrt を使うと扱いやすい。 切り上げ除算は (M + a - 1) // a で整数のまま計算できる。

コード

import sys
import math


def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())

    if n * n < m:
        print(-1)
        return

    answer = n * n
    limit = min(n, math.isqrt(m) + 1)

    for a in range(1, limit + 1):
        b = (m + a - 1) // a
        if b <= n:
            answer = min(answer, a * b)

    print(answer)


if __name__ == "__main__":
    solve()

つまずきポイント

a を N まで全部見る必要はない。 a と b を入れ替えても積は同じなので、 小さい側だけを代表として調べればよい。

まとめ

片方を固定すると、もう片方は切り上げ除算で一意に決まる。 積の対称性で探索範囲を縮めると、候補を十分少なくできる。
