AtCoder Study Notes

ABC356 D - Masked Popcount

k を全列挙せず、M で残るビットごとに、0..N で1が何回立つかを数える。

要約 考察 実装 コード
Article

問題の要約

k = 0..N について popcount(k & M) を足し合わせ、 その値を 998244353 で割った余りとして求める。

問題ページ: AtCoder ABC356 D - Masked Popcount

考察

N が大きいため、k を1つずつ調べることはできない。 ただし、式に出てくる & と popcount はどちらもビット単位で考えられる。

M のビットが0である場所は、k & M でも必ず0になる。 よって、答えに寄与するのは M のビットが1である位置だけである。

各ビット位置 i について、0..N の中で 2^i の位が1になる回数を数える。 その回数を、M の1ビットの位置だけ足せばよい。 

2^i の位:
0 が 2^i 個
1 が 2^i 個
この周期を繰り返す

実装の注意点

0..N には N + 1 個の数がある。 2^i の位は周期 2^(i+1) で、各周期に 2^i 個の1がある。 端数部分では、1が出る区間に入った分だけを足す。

コード

MOD = 998244353


def count_ones_until_n(n, bit_index):
    total_numbers = n + 1
    one_length = 1 << bit_index
    cycle_length = one_length * 2

    full_cycles = total_numbers // cycle_length
    remainder = total_numbers % cycle_length

    ones = full_cycles * one_length
    extra = remainder - one_length
    if extra < 0:
        extra = 0
    if extra > one_length:
        extra = one_length

    return ones + extra


def solve():
    n, m = map(int, input().split())

    answer = 0
    for bit_index in range(60):
        if ((m >> bit_index) & 1) == 0:
            continue
        answer += count_ones_until_n(n, bit_index)
        answer %= MOD

    print(answer)


if __name__ == "__main__":
    solve()

つまずきポイント

popcount を各 k に対して計算する発想から離れることが大切。 「各ビットが答えに何回1として寄与するか」を数えると、60個程度のビットを見るだけで済む。

まとめ

M の1ビットだけを対象にし、0..N でそのビットが立つ回数を周期で数える。 各ビットの寄与を足し合わせたものが答えになる。
