ABC334 D - Reindeer and Sleigh

小さい必要数から選んだ累積和を作り、各クエリは二分探索で答える。

要約 考察 実装 コード
Article

問題の要約

各ソリを引くために必要なトナカイ数が与えられる。 各クエリでは、トナカイが X 匹いるとき、最大で何台のソリを引けるかを求める。

問題ページ: AtCoder ABC334 D - Reindeer and Sleigh

考察

出力するのはソリの番号ではなく台数である。 そのため、何台引けるかだけを考えるなら、必要なトナカイ数が少ないソリから選ぶのが最適になる。

必要数を昇順に並べ、累積和を作る。 累積和の k 番目は、「k 台引くために必要な最小トナカイ数」を表す。

クエリ X に対しては、累積和の中で X 以下の値がいくつあるかを数えればよい。 累積和は昇順なので、二分探索で高速に求められる。

解法方針

  1. 必要なトナカイ数の配列を昇順にソートする。
  2. 先頭からの累積和を作る。
  3. 各クエリ X について、累積和の中で X 以下の個数を二分探索で求める。

実装の注意点

累積和は大きくなるため、言語によっては整数型の範囲に注意する。 Python ではそのまま整数で扱える。 bisect_right(prefix, x) は、x 以下の要素数を返す。

コード

import sys
from bisect import bisect_right


def solve():
    input = sys.stdin.readline
    n, q = map(int, input().split())
    r = list(map(int, input().split()))

    r.sort()

    prefix = []
    total = 0
    for value in r:
        total += value
        prefix.append(total)

    answers = []
    for _ in range(q):
        x = int(input())
        answers.append(str(bisect_right(prefix, x)))

    print("\n".join(answers))


if __name__ == "__main__":
    solve()

つまずきポイント

各クエリで毎回ソリを選び直して線形に数えると間に合わない。 事前に「台数ごとの最小必要数」を累積和として作っておくと、各クエリは二分探索だけになる。

まとめ

最大台数を直接考えるのではなく、k 台引くための最小必要数に変換する。 ソート済みの累積和を使えば、各クエリを高速に処理できる。
