ABC337 E - Bad Juice

各ジュースに異なるビット列を割り当て、返ってきた結果から番号を復元する。

要約 考察 実装 コード
Article

問題の要約

腐ったジュースが1本だけある。 友人に飲ませる組み合わせを設計し、翌日の結果から腐ったジュースの番号を特定する。

問題ページ: AtCoder ABC337 E - Bad Juice

考察

友人が M 人いると、翌日に得られる結果は長さ M の 0 / 1 文字列である。 これは全部で 2^M 通りある。

ジュースが N 本あるので、すべてを区別するには少なくとも 2^M >= N が必要である。 したがって、この条件を満たす最小の M が必要な友人の数になる。

あとは、各ジュースに異なる長さ M のビット列を割り当てる。 ビット列の 1 の位置に対応する友人へ、そのジュースを飲ませる。 返ってきた文字列と同じビット列を持つジュースが、腐ったジュースである。

解法方針

  1. 2^M >= N を満たす最小の M を求める。
  2. ジュース番号 1..N に、0..N-1 の M 桁二進数を割り当てる。
  3. 各友人には、その桁が 1 のジュースを飲ませる。
  4. 返ってきた結果文字列を二進数として読み、対応するジュース番号を答える。

実装の注意点

この問題はインタラクティブ問題なので、実際の提出では出力のたびに flush が必要である。 また、0 から割り当てると、N が2の冪の場合でも M 桁に収まる。

コード

import sys


def solve():
    n = int(input())

    m = 0
    while (1 << m) < n:
        m += 1

    print(m, flush=True)

    patterns = [format(i, f"0{m}b") for i in range(n)]
    for friend in range(m):
        drinks = []
        for juice in range(n):
            if patterns[juice][friend] == "1":
                drinks.append(juice + 1)
        print(len(drinks), *drinks, flush=True)

    s = input().strip()
    answer = int(s, 2) + 1
    print(answer, flush=True)


if __name__ == "__main__":
    solve()

つまずきポイント

友人に何を飲ませるかを直接考えるより、 「腐っていたときに返ってくる結果」をジュースごとに先に決めると分かりやすい。

まとめ

結果文字列を識別子として使う問題である。 M 人で 2^M 通りを区別できるので、最小の M を選び、各ジュースに固有のビット列を割り当てる。
