ABC326 D - ABC Puzzle

行として正しい候補を先に作り、上から選びながら列条件を満たす盤面を探す。

要約 考察 実装 コード
Article

問題の要約

N x N の盤面に A, B, C を配置する。 各行・各列には3文字が1個ずつ入り、各行の左から最初の文字と各列の上から最初の文字が指定された文字列と一致する必要がある。

問題ページ: AtCoder ABC326 D - ABC Puzzle

考察

N は最大でも 5 なので、候補を試す方針が使える。 ただし盤面全体をマスごとに作るより、まず「1行として正しい文字列」を作ると整理しやすい。

1行の候補は、長さ N の文字列で、 A, B, C がちょうど1個ずつ入り、 左から最初に見える文字がその行に指定された文字と一致するものだけである。

各行から候補を1つずつ選べば、行条件は満たせる。 残る列条件は、行を置くたびに「同じ列に同じ文字が2回入らないか」「その列で初めて見える文字が指定と合うか」を確認して枝刈りする。

解法方針

  1. 各行について、行条件を満たす候補文字列を列挙する。
  2. 上の行から順に、候補を1つ選んで盤面へ置く。
  3. 置いた文字が、列ごとの個数や最初に見える文字の条件に矛盾しないか確認する。
  4. 全行を置けたら、各列に A, B, C が1個ずつあるか最終確認する。
  5. 見つかれば Yes と盤面を出力し、見つからなければ No を出力する。

実装の注意点

列の上端文字は、ある列に初めて A, B, C のいずれかを置く瞬間に決まる。 その文字が指定と違うなら、その候補はそこで捨てられる。

バックトラックでは、行を置いたときに変更した列の個数と上端文字を戻す必要がある。 実装を単純にするため、置く前の状態をコピーして再帰する形でも十分間に合う。

コード

import sys


def first_visible(line):
    for char in line:
        if char != ".":
            return char
    return ""


def make_row_candidates(n, expected):
    candidates = []

    for a_pos in range(n):
        for b_pos in range(n):
            if b_pos == a_pos:
                continue
            for c_pos in range(n):
                if c_pos == a_pos or c_pos == b_pos:
                    continue

                row = ["."] * n
                row[a_pos] = "A"
                row[b_pos] = "B"
                row[c_pos] = "C"

                if first_visible(row) == expected:
                    candidates.append("".join(row))

    return candidates


def solve():
    input = sys.stdin.readline
    n = int(input())
    r = input().strip()
    c = input().strip()

    row_candidates = [make_row_candidates(n, r[i]) for i in range(n)]
    board = []
    column_counts = [{"A": 0, "B": 0, "C": 0} for _ in range(n)]
    column_first = [""] * n

    def can_place(row):
        for col, char in enumerate(row):
            if char == ".":
                continue
            if column_counts[col][char] == 1:
                return False
            if column_first[col] == "" and char != c[col]:
                return False
        return True

    def place(row):
        changed_first = []
        for col, char in enumerate(row):
            if char == ".":
                continue
            column_counts[col][char] += 1
            if column_first[col] == "":
                column_first[col] = char
                changed_first.append(col)
        return changed_first

    def remove(row, changed_first):
        for col, char in enumerate(row):
            if char != ".":
                column_counts[col][char] -= 1
        for col in changed_first:
            column_first[col] = ""

    def search(row_index):
        if row_index == n:
            for col in range(n):
                if column_counts[col]["A"] != 1:
                    return False
                if column_counts[col]["B"] != 1:
                    return False
                if column_counts[col]["C"] != 1:
                    return False
                if column_first[col] != c[col]:
                    return False
            return True

        for row in row_candidates[row_index]:
            if not can_place(row):
                continue
            board.append(row)
            changed_first = place(row)
            if search(row_index + 1):
                return True
            remove(row, changed_first)
            board.pop()

        return False

    if not search(0):
        print("No")
        return

    print("Yes")
    print("\n".join(board))


if __name__ == "__main__":
    solve()

つまずきポイント

行条件だけで候補を作ると、列条件を満たさない盤面も多く残る。 行を置く途中で列の重複と上端文字を確認して、早めに枝を切ることが大切である。

まとめ

小さい制約を利用して、行候補の列挙とバックトラックで構成する。 条件を行と列に分けると、盤面全体を直接試すより見通しよく実装できる。
