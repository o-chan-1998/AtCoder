ABC268 D - Unique Username

使う文字列の順番と、間に入れるアンダースコアの個数で候補は決まる。 長さ16以下という制限を使い、作れる候補を全探索する。

要約 考察 実装 コード
Article

問題の要約

N 個の文字列を好きな順番に並べ、隣同士の間に1個以上の _ を入れて ユーザー名を作る。長さが3以上16以下で、禁止文字列のどれとも一致しないものを1つ出力する。

問題ページ: AtCoder ABC268 D - Unique Username

考察

候補は自由な文字列ではなく、S_i の並べ方と _ の個数だけで決まる。 N は最大8なので、文字列の順列は最大でも 8! 通りで試せる。

ある順番を固定したら、まず各すき間に _ を1個ずつ置く。 その時点の長さを基準にして、16文字まで余っている文字数を各すき間へ配る。 候補が禁止集合に入っていなければ、その場で答えにできる。

順番

ab→cd

S_i の並べ方を1つ固定する。

すき間

_+余り

各すき間には最低1個の _ が必要。

判定

候補OK

長さと禁止文字列への一致を確認する。

解法方針

  1. 禁止文字列 T_i を集合に入れる。
  2. S_i のすべての順列を試す。
  3. 各順列について、最低限の _ を入れた長さを計算する。
  4. 16文字まで追加できる _ を、再帰で各すき間へ配る。
  5. 禁止集合にない候補が見つかったら出力し、なければ -1 を出力する。

実装の注意点

N = 1 のときはすき間がないため、S_1 そのものだけを判定する。 禁止文字列は最大で多いので、リストではなく集合で照合する。

コード

from itertools import permutations


def build_username(order, underscore_counts):
    username = order[0]
    for i, count in enumerate(underscore_counts):
        username += "_" * count
        username += order[i + 1]
    return username


def search(order, gap_index, remaining_extra, counts, forbidden):
    if gap_index == len(order) - 1:
        candidate = build_username(order, counts)
        if 3 <= len(candidate) <= 16 and candidate not in forbidden:
            return candidate
        return None

    for extra in range(remaining_extra + 1):
        counts.append(1 + extra)
        answer = search(order, gap_index + 1, remaining_extra - extra, counts, forbidden)
        if answer is not None:
            return answer
        counts.pop()

    return None


N, M = map(int, input().split())
S = [input() for _ in range(N)]
forbidden = {input() for _ in range(M)}

for order in permutations(S):
    base_length = sum(len(word) for word in order) + (N - 1)
    if base_length > 16:
        continue

    if N == 1:
        candidate = order[0]
        if 3 <= len(candidate) <= 16 and candidate not in forbidden:
            print(candidate)
            exit()
        continue

    answer = search(order, 0, 16 - base_length, [], forbidden)
    if answer is not None:
        print(answer)
        exit()

print(-1)

まとめ

この問題は、文字列を直接ひねり出すのではなく、候補の作り方を分解するのが重要。 順列とアンダースコアの配分を全探索し、禁止集合で高速に除外すればよい。
