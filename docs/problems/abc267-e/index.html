ABC267 E - Erasing Vertices 2

各頂点を今消すときのコストを持ち、最小コストの頂点から削除していく。

Article

問題の要約

値 A_i を持つ頂点からなる無向グラフがある。 頂点を1つ削除すると、その時点で残っている隣接頂点の値の合計が操作コストになる。 全操作で発生するコストの最大値をできるだけ小さくしたい。

問題ページ: AtCoder ABC267 E - Erasing Vertices 2

考察

まず、頂点 v を今削除したときのコストを cost[v] とする。 これは、まだ残っている隣接頂点の A の合計である。

目的はコストの合計ではなく、途中で出る最大値を小さくすること。 さらに、頂点を削除すると隣接頂点の cost は減るだけで、増えることはない。 そのため、その時点で最小の cost を持つ頂点を削除する方針が自然になる。

ある時点で最小コストが K なら、残っているどの頂点を選んでもコストは K 以上である。 つまり、その残り集合から1つ削除する以上、K 未満で済ませることはできない。 この下限を毎回選んでいくので、記録される最大値が最小になる。

実装の注意点

毎回最小の cost を取り出すため、優先度付きキューを使う。 Python の heapq では値の更新が直接できないため、新しい cost を追加で push し、取り出したときに古い情報なら捨てる。

コード

import heapq
import sys


def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    graph = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        graph[u].append(v)
        graph[v].append(u)

    cost = [0] * n
    for v in range(n):
        for to in graph[v]:
            cost[v] += a[to]

    heap = []
    for v in range(n):
        heapq.heappush(heap, (cost[v], v))

    removed = [False] * n
    answer = 0

    for _ in range(n):
        while True:
            current_cost, v = heapq.heappop(heap)
            if removed[v]:
                continue
            if current_cost != cost[v]:
                continue
            break

        removed[v] = True
        answer = max(answer, current_cost)

        for to in graph[v]:
            if removed[to]:
                continue
            cost[to] -= a[v]
            heapq.heappush(heap, (cost[to], to))

    print(answer)


if __name__ == "__main__":
    solve()

つまずきポイント

削除する頂点自身の値 A_v は、その操作のコストではない。 見るべきなのは、残っている隣接頂点の値の合計である。 また、ヒープ内には古い cost が残るので、取り出し時の検証を忘れない。

まとめ

各頂点の現在コストを管理し、最小コストの頂点から削除する。 削除によって隣接頂点のコストを下げ、発生したコストの最大値を答えとして記録する。
