ABC354 E - Remove Pairs

場に残っているカード集合をbitで表し、現在の手番が勝てるかを判定する。 相手を負け状態へ渡せる手が1つでもあれば勝ち。

要約 考察 実装 コード
Article

問題の要約

各カードには表の数と裏の数がある。手番では、表または裏の数が一致する2枚を選んで取り除く。 取れる手がなくなった人が負ける。先手が勝つかどうかを判定する。

問題ページ: AtCoder ABC354 E - Remove Pairs

考察

盤面は「どのカードが残っているか」で決まる。カード数が多くないため、 残っているカード集合をbit maskで表せば、すべての状態について勝敗を計算できる。

ゲームDPでは、現在の状態から1手進めて相手の負け状態にできるなら現在の状態は勝ち。 どの手を選んでも相手の勝ち状態へ行くなら、現在の状態は負けになる。

状態

10110

bitが1のカードが場に残っている。

手

2枚-

表または裏が同じ2枚を選んで取り除く。

勝ち

相手が負けWin

負け状態へ遷移できる手があれば勝ち。

解法方針

  1. mask を場に残っているカード集合とする。
  2. dp[mask] を、その状態で手番の人が勝てるなら True とする。
  3. 各 mask について、残っている2枚の組をすべて試す。
  4. 取り除ける組なら、2bitを落とした next_mask へ進む。
  5. dp[next_mask] が False なら、現在の状態は True。

実装の注意点

next_mask は現在よりカード枚数が2枚少ない状態なので、 mask を小さい順に見ていくと、遷移先の勝敗はすでに計算済みになる。

コード

N = int(input())
A = []
B = []

for _ in range(N):
    a, b = map(int, input().split())
    A.append(a)
    B.append(b)

total = 1 << N
dp = [False] * total

for mask in range(total):
    for i in range(N):
        if not (mask & (1 << i)):
            continue

        for j in range(i + 1, N):
            if not (mask & (1 << j)):
                continue
            if A[i] != A[j] and B[i] != B[j]:
                continue

            next_mask = mask ^ (1 << i) ^ (1 << j)
            if not dp[next_mask]:
                dp[mask] = True
                break

        if dp[mask]:
            break

initial = total - 1
print("Takahashi" if dp[initial] else "Aoki")

まとめ

2人ゲームでは、「相手を負け状態へ送れるか」を基準にすると勝敗を定義しやすい。 残っているカード集合をbitで持つことで、状態を整数として扱える。
