ABC436 D - Teleport Maze

歩行もワープも1回の行動として数える迷路の最短距離問題。 同じ文字のワープ先をまとめて持ち、各文字のワープ展開は一度だけ行う。

要約 考察 実装 コード
Article

問題の要約

迷路には空きマス、障害物、英小文字のワープマスがある。 上下左右への歩行と、同じ文字のワープマスへの移動を使い、左上から右下への最小行動回数を求める。

問題ページ: AtCoder ABC436 D - Teleport Maze

考察

歩行もワープもコストは1なので、最短行動回数は BFS で求められる。 各マスからは上下左右へ進めるほか、英小文字のマスなら同じ文字の全マスへワープできる。

ただし、同じ文字のワープを毎回すべて展開すると重くなる。 ある文字のワープ先一覧は、BFSでその文字に初めて到達したときに一度だけ展開すればよい。 その後に同じ文字へ到達しても、前より得なワープにはならないから。

歩行

隣接+1

障害物と盤面外には進めない。

ワープ

a→a

同じ文字のマスへ1回で移動できる。

省略

展開済みskip

同じ文字の全展開は1回だけ。

解法方針

  1. 各英小文字について、その文字が置かれているマスの一覧を先に作る。
  2. dist[r][c] を始点からの最小行動回数として BFS する。
  3. 各マスから上下左右の空きマスまたはワープマスへ進む。
  4. 現在マスが英小文字なら、同じ文字の全マスへ距離 +1 で進む。
  5. 同じ文字のワープ展開は used_warp で一度だけにする。

実装の注意点

ワープ先一覧を毎回なめると、同じ文字が多い盤面で間に合わない。 used_warp に入っている文字は再展開しないことで、各マスは歩行探索とワープ探索で高々定数回だけ扱われる。

コード

from collections import deque


H, W = map(int, input().split())
S = [input() for _ in range(H)]

warp_cells = {}
for r in range(H):
    for c in range(W):
        ch = S[r][c]
        if "a" <= ch <= "z":
            if ch not in warp_cells:
                warp_cells[ch] = []
            warp_cells[ch].append((r, c))

dist = [[-1] * W for _ in range(H)]
queue = deque([(0, 0)])
dist[0][0] = 0
used_warp = set()
directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

while queue:
    r, c = queue.popleft()
    current = dist[r][c]

    for dr, dc in directions:
        nr = r + dr
        nc = c + dc
        if not (0 <= nr < H and 0 <= nc < W):
            continue
        if S[nr][nc] == "#":
            continue
        if dist[nr][nc] != -1:
            continue

        dist[nr][nc] = current + 1
        queue.append((nr, nc))

    ch = S[r][c]
    if "a" <= ch <= "z" and ch not in used_warp:
        used_warp.add(ch)
        for nr, nc in warp_cells[ch]:
            if dist[nr][nc] != -1:
                continue
            dist[nr][nc] = current + 1
            queue.append((nr, nc))

print(dist[H - 1][W - 1])

まとめ

行動回数がすべて1なので、基本は BFS。 ワープは同じ文字のマスへの一括遷移だが、文字ごとに一度だけ展開すると無駄な全探索を避けられる。
