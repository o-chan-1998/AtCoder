直線と円環の色の数え上げ

隣り合う位置の色を異ならせるとき、直線なら直前だけを見ればよい。 円環では最後に最初の位置へ戻るため、最初の色との関係を状態として持つ必要が出てくる。

Derived Note

このページの目的

ABC307 E - Distinct Adjacent の考察で出てくる same / diff が、なぜ円環で必要になるのかを確認する。

直線の場合

位置が直線に並んでいる場合、隣接関係は次のようになる。 

1 - 2 - 3 - ... - N

位置 1 は自由に選べるので M 通り。 位置 2 以降は、直前の色と同じでなければよい。 そのため、各位置で選べる色は M - 1 通りになる。 

M * (M - 1)^(N - 1)

直線では、最後まで進んだあとに追加で確認する相手がいない。 だから、最初の色との関係を状態として持つ必要がない。

円環の場合

円環では、位置 N と位置 1 も隣接する。 

1 - 2 - 3 - ... - N
|                 |
+-----------------+

位置 2 から N まで順に決める間は、直前と違う色を選べばよい。 しかし最後に、位置 N が位置 1 と違う色かどうかを確認する必要がある。

そのため、円環では「今の色が位置 1 の色と同じか、違うか」を覚えておく価値がある。 これが same / diff の状態になる。

見方の違い

直線

次に選ぶ色は、直前の色だけを避ければよい。

最後に最初の色と比べる必要がない。

円環

次に選ぶ色は、直前の色を避ける。

最後に最初の色とも比べる必要がある。

つまり、直線では「直前と違う」を掛け続ければよい。 円環ではそれだけだと最後の条件を取りこぼすため、最初の色を基準にした状態を持つ。
